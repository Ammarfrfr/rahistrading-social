## What to give me so I can post

One thing: a **Buffer API key**.

1. <https://publish.buffer.com/settings/api> → create a key.
2. Paste it to me.

That is all. With the key I can read your channels, push the five scheduled posts, and check
what published. It cannot change your password, and you can revoke it with one click on the
same page.

**Never give me — or anyone — the Instagram or Facebook password.** Nobody needs it for this,
2FA stays on, and any message asking for it is a scam. Same for "session cookies" or a
screenshot of a login code.

If you would rather not hand over a key at all, the drag-drop path in
`docs/automation-setup.md` still works — five posts, about 15 minutes a week, nothing shared.
